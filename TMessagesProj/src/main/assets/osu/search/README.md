# osu! search artwork

drawable-nodpi/osu_search_logo.png is the unmodified original osu! logo texture:
https://github.com/ppy/osu-resources/blob/master/osu.Game.Resources/Textures/Menu/logo.png

Artwork by team osu!, ppy Pty Ltd. Resource licence: CC BY-NC 4.0;
the full licence is bundled at ../argon-pro/resources-LICENCE.md.
osu_search_badge.xml places the transparent original texture on an osu! pink circle.

Beatmap list thumbnails are fetched from the official assets.ppy.sh CDN and
cached by the client's ImageLoader. They are centre-cropped into 42dp squares.
